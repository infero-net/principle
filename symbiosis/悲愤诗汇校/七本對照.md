# 《悲憤詩》七本對照

《後漢書·列女傳·董祀妻》蔡琰《悲憤詩》關鍵字，七個本子的影印截圖逐字對照。每行一個字，每列一個本子，從左到右大致按刊刻年代排。紅框是要看的字，上下各留一字。點圖看不帶紅框的大圖。表頭點本子名去原書。

結論、判據和做法見 [README](README.md)；09333 同卷目旁與耳旁的比對見 README 第三節。
