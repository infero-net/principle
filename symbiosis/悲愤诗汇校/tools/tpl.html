悲憤詩七本對照《後漢書·列女傳·董祀妻》　關鍵字影印逐字比讀

每行一個字，每列一個本子，從左到右大致按刊刻年代排。格中是影印截圖，紅框是要看的字，上下各留一字作上下文。點圖看不帶紅框的大圖，表頭點本子名去原書。

今夜所見

  1. 徒 / 走 不是按年代一刀切。作「走」：百衲本、08657、汲古閣本；作「徒」：09333、白鷺洲 08656、北監本、五洲同文本（殿本系）。明清兩大官刻（北監、殿本）都作「徒」。
  2. 縣 / 懸：只有百衲本和 08657 作「縣」，其餘五本作「懸」。
  3. 白鷺洲 08656 與 09333 卷八十四（一經堂本）同為八行十六字，其一部分每欄起訖逐欄相同；到其二才錯開。
  4. 眺，不是聎。09333「登高遠□望」左旁的右豎在下端伸出提畫，乍看像耳旁。分辨要看右上角：耳旁首橫向右穿出右豎（聊、聽、恥）；目旁右上是橫折封口（眇、盱）。此字右上封口，是目旁。見下方同卷對照。
  5. 怚 / 怛、祐 / 祜、冷泠 這幾處筆畫細，掃描解析度有限，沒有替你判，請點開大圖看。

09333 同卷目旁與耳旁

全部取自國圖 09333《後漢書》卷八十四（配嘉定元年一經堂本）影印，原圖截取，未修飾。看左旁的右上角：耳旁首橫向右穿出右豎，目旁是橫折封口。下端兩者的右豎都伸出提畫之下，分不開。

做法與限度

國圖三本取自中華古籍資源庫閱讀器截圖（一屏兩個半葉）；百衲本、北監本、汲古閣本、五洲同文本取自識典古籍的原圖。每本先讀出每欄欄首字作錨點，欄內按格均分定位，所以紅框偶爾會偏小半格，以上下文為準。

排序只是大致：百衲本按通常著錄的「景宋紹興本」排在最前，今晚沒核到原書題記；08657 只知是宋刻元修，刻年未定。中華書局點校本有版權，沒有收。
